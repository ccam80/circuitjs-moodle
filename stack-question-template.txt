[[script type="module"]]
// Import the STACK-JS bridge library
import {stack_js} from '[[cors src="stackjsiframe.js"/]]';

// Request write access to the hidden STACK input "ans1"
const inputId = await stack_js.request_access_to_input("ans1", true);
const stackInput = document.getElementById(inputId);

// Listen for simulation data relayed by bridge.html
window.addEventListener('message', function(event) {
  if (!event.data || event.data.type !== 'circuitjs-data') return;

  var vout = event.data.values['vout'];
  if (vout === null || vout === undefined) return;

  // Update the visual readout
  document.getElementById('voltage-display').textContent = vout.toFixed(3);
  document.getElementById('status').textContent = '';

  // Write the value into the STACK input for Maxima to grade
  stackInput.value = vout.toFixed(6);
  stackInput.dispatchEvent(new Event('change'));
});

This example grades the current through element index 3 (e.g. a resistor).

  bridge.html?ctz=...&elements=3:current&rate=2

tol_i: 0.0005;

[[script type="module"]]
import {stack_js} from '[[cors src="stackjsiframe.js"/]]';

---------------------------------------------------------------------------
Bridge URL

bridge.html?ctz=...&nodes=vout&elements=3:current&editable=true&rate=2

---------------------------------------------------------------------------
FIELD: Question text — script block

[[script type="module"]]
import {stack_js} from '[[cors src="stackjsiframe.js"/]]';

const vId = await stack_js.request_access_to_input("ans1", true);
const vInput = document.getElementById(vId);
const iId = await stack_js.request_access_to_input("ans2", true);
const iInput = document.getElementById(iId);

  if (!event.data || event.data.type !== 'circuitjs-data') return;

  v = event.data.values['3:current'];
  if (v !== null && v !== undefined) {
    document.getElementById('val-current').textContent = v.toFixed(6);
    iInput.value = v.toFixed(6);
    iInput.dispatchEvent(new Event('change'));
  }

  document.getElementById('status').textContent = '(live)';
});

===========================================================================
EXAMPLE 5: Component Integrity Checking
===========================================================================
Prevent students from modifying restricted components. The bridge
detects unauthorized edits and streams integrity=0 when they occur.

The bridge URL includes editableIndices= to specify which element
indices students may edit. All other elements are locked.

---------------------------------------------------------------------------
FIELD: Question variables (Maxima)
---------------------------------------------------------------------------
target_ans1: 3.3;
tol_ans1: 0.1;
expected_integrity: 1;

---------------------------------------------------------------------------
Bridge URL
---------------------------------------------------------------------------
bridge.html?ctz=...&nodes=vout&editableIndices=0,2&editable=true&rate=2

(Elements 0 and 2 are student-editable; all others are locked.)

---------------------------------------------------------------------------
FIELD: Question text — hidden integrity input
---------------------------------------------------------------------------
<div style="display:none;">
  <p>[[input:ans1]] [[validation:ans1]]</p>
  <p>[[input:ans_integrity]] [[validation:ans_integrity]]</p>
</div>

---------------------------------------------------------------------------
FIELD: Question text — script block
---------------------------------------------------------------------------
[[script type="module"]]
import {stack_js} from '[[cors src="stackjsiframe.js"/]]';

const ans1Id = await stack_js.request_access_to_input("ans1", true);
const ans1Input = document.getElementById(ans1Id);
const intId = await stack_js.request_access_to_input("ans_integrity", true);
const intInput = document.getElementById(intId);

window.addEventListener('message', function(event) {
  if (!event.data || event.data.type !== 'circuitjs-data') return;
  var v;

  v = event.data.values['vout'];
  if (v !== null && v !== undefined) {
    document.getElementById('val-ans1').textContent = v.toFixed(4);
    ans1Input.value = v.toFixed(6);
    ans1Input.dispatchEvent(new Event('change'));
  }

  v = event.data.values['integrity'];
  if (v !== null && v !== undefined) {
    intInput.value = v.toString();
    intInput.dispatchEvent(new Event('change'));
  }

  document.getElementById('status').textContent = '(live)';
});
[[/script]]

---------------------------------------------------------------------------
FIELD: Inputs
---------------------------------------------------------------------------
ans1:          numerical, tans=target_ans1, hidden
ans_integrity: numerical, tans=expected_integrity, hidden

---------------------------------------------------------------------------
FIELD: PRT (with integrity gate)
---------------------------------------------------------------------------
PRT name: prt1
Value: 1

NODE 0 — Integrity gate:
  SAns:  ans_integrity
  TAns:  expected_integrity
  Answer test: AlgEquiv
  Quiet: Yes

  TRUE  → next node 1 (proceed to value check)
  FALSE → Score = 0, feedback:
    <p>One or more restricted circuit components were modified.
    Your answer cannot be graded.</p>

NODE 1 — Value check:
  SAns:  ans1
  TAns:  target_ans1
  Answer test: NumAbsolute
  Test option: tol_ans1

  TRUE  → Score = 1, feedback: Correct
  FALSE → Score = 0, feedback: Incorrect

---------------------------------------------------------------------------
How it works
---------------------------------------------------------------------------
1. On first circuit load (onanalyze), the bridge captures a baseline
   "signature" for every element (type code + parameter values).
2. When the circuit is re-analyzed (student edits a component), the
   bridge re-extracts signatures and compares non-editable elements.
3. If any non-editable element's signature changed, integrity = 0.
4. The PRT checks integrity FIRST (Node 0). If it fails, the student
   gets zero marks with a clear message. Only if integrity passes
   does the value check (Node 1) run.


===========================================================================
SUPPORTED MEASUREMENT PROPERTIES
===========================================================================

  Method           | Bridge param         | Key in data.values    | Unit
  -----------------+----------------------+-----------------------+------
  Node voltage     | nodes=vout           | "vout"                | V
  Element current  | elements=3:current   | "3:current"           | A
  Element voltage  | elements=3:voltageDiff| "3:voltageDiff"      | V
  Element power    | elements=3:power     | "3:power"             | W
  Label current    | measures=R1:current  | "R1:current"          | A
  Label voltage    | measures=R1:voltageDiff| "R1:voltageDiff"    | V
  Label power      | measures=R1:power    | "R1:power"            | W
  Label voltage0   | measures=R1:voltage0 | "R1:voltage0"         | V
  Label voltage1   | measures=R1:voltage1 | "R1:voltage1"         | V

Node voltages:       nodes=vout,vmid       (getNodeVoltage API)
Index-based:         elements=3:current    (by element index)
Label-based:         measures=R1:current   (by element label)
All can be combined in one URL.

Integrity checking:  editableIndices=0,2   (element indices students may edit)
                     Streams integrity=1 (ok) or 0 (tampered) in data.values.


===========================================================================
NOTES
===========================================================================
1. Replace BRIDGE_URL with your actual GitHub Pages URL.

2. Replace PUT_YOUR_CTZ_HERE with the ctz value from your circuit.
   To get this:
   a) Open https://falstad.com/circuit/circuitjs.html
   b) Build your circuit
   c) To label a node: Draw -> Outputs and Labels -> Add Node Label,
      then place it on the wire and set its name (e.g. "vout")
   d) File -> Export As Link
   e) Copy just the ctz=... parameter value from the generated URL

3. The "Hide input" setting prevents students from seeing/editing the
   hidden ans1 field that receives the voltage value.

4. You can add more nodes by extending both:
   - The bridge URL:  &nodes=vout,vmid,vin
   - The message listener in the [[script]] block

5. For multi-value grading (e.g. check both voltage AND current),
   add more STACK inputs (ans2, ans3) and more PRT nodes, each
   reading a different value from event.data.values.

6. To grade current through a component:
   a) Find the element's index using the question generator's
      "Refresh from Simulator" or test-bridge.html
   b) Add elements=3:current to the bridge URL (where 3 is the index)
   c) The value key in event.data.values will be '3:current'
   d) Supported properties: current, voltageDiff, power

7. For impedance/resistance grading:
   Read both voltageDiff and current for the same element, then compute
   Z = V / I in a Maxima feedback variable. See Example 4 above.

8. Element indices are stable when loading from a CTZ parameter (the
   circuit export is deterministic). Editing a component's VALUE does
   not change indices. Adding or removing components WILL change
   indices — use integrity checking to detect this.

9. Component integrity checking (Example 5):
   - Add editableIndices=0,2 to the bridge URL (comma-separated element indices)
   - The bridge captures element signatures on first load
   - If a student edits a non-editable element, integrity flips to 0
   - Use test-bridge.html to find element indices (circuitjs-elements message)
   - Editing element values (right-click -> Edit) doesn't change indices
   - Adding/removing elements WILL shift indices — the integrity check catches this

10. Finding element indices:
    - Load your circuit in test-bridge.html
    - The circuitjs-elements message lists all elements with their indices
    - Element ordering matches getElements() and export line order
    - CTZ loads produce deterministic element ordering
